Personal Library

Save articles, web serials, EPUBs and PDFs, and read them offline. Everything stays on your computer.

First-launch steps

Save from the web

Paste a link and the app downloads the page, strips out the clutter and keeps a clean copy. Multi-chapter stories download all at once. There are dedicated parsers for Archive of Our Own, FanFiction.net, Royal Road, Wattpad and others, and a general one for everything else.

Read

Web pages, EPUBs and PDFs each open in their own reader. Change the font, size, spacing, page width and theme, and read by scrolling or page by page. Select any word to look it up in the built-in dictionary, which works offline.

Highlight and take notes

Highlight passages in four colours, attach notes and add bookmarks in every reader. One page collects all your highlights across the library, where you can filter them, group them and export them as Markdown or plain text.

Search everything

Search covers the full text of everything you've saved, not just titles, and matches partial words as you type. Tags, collections and reading status keep the rest organised.

Find something new

The Discover page suggests fanfiction and books based on what's already in your library, using AO3, FanFiction.net and Open Library. The matching runs on your computer, so your reading history isn't sent anywhere.

Sync, if you want it

A free account keeps tags, collections, progress and highlights in sync between computers within a few seconds. Book files are uploaded only for the items you choose. Without an account, nothing leaves your computer.

Installing

The app isn't code-signed yet, so macOS and Windows warn you the first time you open it.

macOS
Open the .dmg and drag the app into Applications. Right-click the app, choose Open, then click Open again. You only need to do this once. Updates are manual on macOS: download the new version and replace the app.
Windows
Run the installer. If you see “Windows protected your PC”, click More info, then Run anyway. The app offers updates when it starts.
Linux
Make the AppImage executable with chmod +x and run it. The app offers updates when it starts.

Your library is kept in the app's data folder and survives updates and reinstalls. Settings → Data → Export Library saves all of it to a single file. Full install notes
